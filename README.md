# Telegram-bot-for-download-videos-RU
Асинхронный Telegram-бот на aiogram 3 и yt-dlp для скачивания видео (MP4) и извлечения аудио (MP3) по ссылкам. Поддерживает пакетную загрузку и автоочистку чата. Бот предназначен только для личного использования и будет плохо работать с нескольким пользователями одновременно
