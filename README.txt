# Telegram-bot-for-download-videos-RU
Асинхронный Telegram-бот на aiogram 3 и yt-dlp для скачивания видео (MP4) и извлечения аудио (MP3) по ссылкам. Поддерживает пакетную загрузку и автоочистку чата. Бот предназначен только для личного использования и будет плохо работать с нескольким пользователями одновременно

# Telegram-бот для загрузки видео и MP3

Бот скачивает видео и извлекает аудио в MP3 по прямым ссылкам. Он работает в двух режимах: видео (`/v`) и MP3 (`/m`). В одном сообщении можно отправить несколько ссылок, и они обрабатываются параллельно.

## Возможности

- Скачивание видео в MP4 с приоритетом разрешения 720p и ограничением размера 50 МБ.
- Извлечение аудио в MP3 с битрейтом 192 kbps.
- Параллельная обработка нескольких ссылок из одного сообщения.
- Кнопка «Очистить чат бота» (или команда `/clear`) удаляет отправленные ботом файлы и служебные сообщения.
- Автоматическая установка и обновление зависимостей при запуске

## Требования

- Python 3.13 или новее (но aiogram пока работает стабильно на 3.13)
- Токен Telegram-бота, который можно получить у @BotFather
- Впн или другие обходы блокировки если у вас недоступен Телеграм, ютуб и другие сайты

Также нужно самостоятельно установить ffmpeg в папку где находится код, чтобы он выглядел так ffmpeg/bin/ffmpeg.exe
https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip (полное название скачанной папки надо переименовать просто в ffmpeg)

## Установка и запуск

1. Скачайте репозиторий или скопируйте файлы `bot.py` и `deps.py` в одну папку.
2. Запустите бота:

   ```bash
   python bot.py
   ```

4. При первом запуске будет создан файл `token.txt` с текстом-заглушкой. Откройте его, вставьте токен бота и сохраните.
5. Запустите `python bot.py` ещё раз.

Первый запуск может занять несколько минут, так как скрипт скачивает все пакеты. Дальнейшие запуски проходят быстрее.

## Команды

/start - Приветствие и включение режима видео 
/v - Переключение в режим видео 
/m - Переключение в режим MP3 
/clear - Удаление отправленных ботом файлов 

## Ограничения и частые ошибки

- **Только прямые ссылки.** Бот принимает ссылки на отдельные видео. Плейлисты обрабатываются, но для больших списков это займёт много времени.
- **Файлы больше 50 МБ** Telegram не принимает, поэтому такие ссылки пропускаются с сообщением об ошибке.
- **Ошибка 403** означает ограничение со стороны YouTube. Обычно помогает обновление `yt-dlp`, которое выполняется при каждом запуске.
- **Одна из ссылок не скачалась.** Ошибка появляется в статусном сообщении для этой ссылки. Подробности также выводятся в консоли.
- **Нестандартный формат.** Если yt-dlp сохранил видео не в MP4, бот может не найти файл. Причина указана в консоли.
